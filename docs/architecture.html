2. Assessment data flow

Farmer opens Vision → picks a camp → enters livestock → (optional photos) → runs assessment
  1. Backend loads camp (farmer-provided data)
  2. Fetches live Open-Meteo weather for camp coordinates
  3. Searches seed data for comparable research plots
  4. Computes livestock/ha (LSU) and grazing duration
  5. Gemini tool-calling agent combines evidence into a structured assessment
  6. Result saved to PostgreSQL with evidence, confidence, and limitations
  7. Farmer can ask follow-ups in the AI advisor chat
